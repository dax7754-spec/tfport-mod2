# TF Port — мод для Minecraft 1.21.1 (NeoForge)

Классы, оружие и боты в стиле командного шутера. Весь код и все текстуры оригинальные.

## Что внутри

**Классы** — команда `/tfclass <scout|soldier|heavy|medic|none>` меняет здоровье и скорость и выдаёт набор оружия. Класс сохраняется после смерти.

| Класс | Здоровье | Скорость | Набор |
|---|---|---|---|
| Разведчик | 20 | +33% | Дробовик, Бита |
| Солдат | 32 | −20% | Ракетомёт, Уравнитель |
| Тяжёлый | 48 | −23% | Миниган, Сэндвич |
| Медик | 24 | +7% | Медиган, Костяная пила |

**Оружие**
- Дробовик: 10 дробинок за выстрел, ПКМ.
- Ракетомёт: ракета взрывается без разрушения блоков, но с отбрасыванием (рокет-джамп работает).
- Миниган: зажать ПКМ, раскрутка 1 секунда, замедляет стрелка.
- Медиган: зажать ПКМ на союзнике, лечит его (не лечит враждебных мобов).

**Боты** — яйцо призыва «Бот». Случайный класс: разведчик и тяжёлый бьют в ближнем бою, солдат стреляет ракетами, медик лечит других ботов.

## Сборка

Нужны JDK 21 и Gradle 8.8+ (или IntelliJ IDEA, она сама всё подтянет).

```
gradle wrapper
./gradlew build        # jar появится в build/libs/
./gradlew runClient    # запустить игру с модом для проверки
```

Версию NeoForge можно поменять в `gradle.properties` (`neo_version`).

## Текстуры

Текстуры-заглушки создаёт `python3 tools/gen_textures.py` (нужен Pillow).
Любой PNG в `src/main/resources/assets/tfport/textures/` можно заменить своим файлом с тем же именем.
